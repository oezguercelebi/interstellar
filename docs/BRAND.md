# Interstellar — Brand Brief

## Who we are

Interstellar is **mission control for ideas**. You type a sentence; a system of
agents designs, builds, and launches a real native app — and you watch it arrive,
live, on an iPhone. The product's entire pitch is *taste*: it must look like it
was designed by the people it claims to replace.

The feeling we sell is the quiet of a control room at the moment telemetry
confirms the burn worked. Not fireworks — **confirmation**.

## Aesthetic direction: "Flight Manual"

Mid-century aerospace documentation × modern editorial. The Apollo press kit:
paper, ink, monospace telemetry, and one signal color used only where attention
is genuinely required. The film's own interiors — white panels, black voids,
instrument lights — not CGI nebulas.

**Restraint is the luxury.** Gradients ask for attention; instruments earn it.

## Principles

1. **Instrument, not ornament.** Every color, line, and motion exists to report
   state or direct action. Decoration that doesn't inform is removed.
2. **Flat color only.** No gradients, no glows. Elevation comes from hairlines
   and true shadow. Confidence reads expensive; shimmer reads cheap.
3. **Serif for wonder, mono for precision.** Headlines speak like a person;
   labels report like a console. That tension is the signature.
4. **One signal.** A single accent — used like the master-alarm light. If
   everything is highlighted, nothing is.
5. **Mechanical motion.** 150–250 ms, eased, no bounce. Machines don't wobble.

## Color

| Token | Value | Role |
|---|---|---|
| Signal | `#FF4D00` (International Orange) | Primary action, live state, focus. Flat, never gradient. |
| Void | `#0A0B0D` | Studio background (dark console) |
| Panel | `#101216` | Studio surfaces |
| Paper | `#F5F4F0` | Landing background (printed manual) |
| Ink | `#16181B` | Text on paper |
| Starlight | `#F4F2EC` | Text on void |
| Hairline | `white/8` · `ink/10` | All structure |

Status lights (green/red/blue) stay functional and small — instrument LEDs,
not theme colors.

## Typography

| Voice | Face | Use |
|---|---|---|
| Wonder | **Instrument Serif** (400, italic) | Display headlines, the one italic word |
| Crew | **Instrument Sans** | UI, body, controls |
| Console | **Azeret Mono** | Telemetry: labels, paths, timestamps, badges — uppercase, tracked wide |

## Mark

A thin orbit ring with a solid signal dot on the path — a craft, mid-orbit.
Flat strokes, current-color, no gradient fills. Wordmark set in Azeret Mono,
uppercase, letterspaced: mission-patch energy.

## Voice

Calm, precise, quietly confident. "Preview is asleep. Reopen to boot a fresh
one." Never exclamation marks, never hype. The work is the wow.
